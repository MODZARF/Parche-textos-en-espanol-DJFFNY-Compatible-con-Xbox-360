# Def Jam Fight For NY - Traducción al Español + Compatibilidad Xbox 360

Parche que traduce todos los textos del juego al español y lo hace compatible con Xbox 360 por retrocompatibilidad.

### ¿Qué incluye este parche?

- **Textos (strings):** Todos los diálogos historia (subtítulos), menús, tutoriales y opciones traducidos al español.
- **Texturas:** Textos del menú principal que vienen como imagen, también traducidos.
- **Compatibilidad Xbox 360:** Incluye el mod de retrocompatibilidad hecho por **Cristian**, para poder ejecutarlo en una 360 con Aurora / FSD.

> **IMPORTANTE:** Este parche (.ZARF) NO contiene ningún archivo del juego original. Solo contiene mis ediciones hex y las de Cristian. Necesitas tu propia copia original del juego.

### Requisitos

- Copia original del juego **Def Jam Fight For NY en su versión NTSC** extraída en carpeta.
- Tener la retrocompatibilidad instalada en tu Xbox 360.
- PC con Python instalado (o usar el .exe compilado).

### ¿Cómo instalarlo?

1.  Ten tu juego original extraído en una carpeta.
2.  Ve a la sección de [**Releases**](../../releases) de este repositorio y descarga:
    - `DJFFNY_TRADU_360.py` (o el .exe)
    - `parche.ZARF`
3.  Pon el archivo `parche.ZARF` en la misma carpeta donde está el script.
4.  Ejecuta el script `DJFFNY_TRADU_360.py`.
5.  Espera unos 5 segundos, se abrirá una ventana para buscar carpeta.
6.  Selecciona la **carpeta raíz** del juego.
7.  Listo.
